WHATSAPP

WhatsApp notices

Private encrypted chats stay private — Orbit can't read them live. Import a chat you've exported yourself instead.

Import an exported chatWhatsApp → open the group → ⋮ More → Export chat.
• Only want the text messages? Choose "Without media" and export from your laptop's WhatsApp — upload the .txt file it gives you below.
• Want photos, videos or voice notes too? WhatsApp only bundles media into the export on a phone, so do this from your phone's WhatsApp app with "Include media" selected, then upload the resulting .zip here (AirDrop/share it to this device first if needed).
Repeat for every group/channel you want tracked — each gets its own tab below and can be removed any time with the × next to its name.

If your Classroom account uses a different email than the one you used to sign in to Orbit, type it below first — Google will open with that account pre-filled (you can still switch accounts on Google's screen).
◔
WhatsApp groups stay private

Orbit cannot read encrypted personal chats. The safe option is for a class representative or admin to forward announcements to a shared college announcement channel.

🔔
Deadline push notifications

Get a real phone/browser alert when a reminder or deadline is about an hour away — even if this tab is closed. Once a reminder is saved, Orbit also emails you the day before that deadline if the app owner has configured email sending.
